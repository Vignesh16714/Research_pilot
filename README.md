## Quick Setup Summary

```bash
# 1. Backend Setup
cd researchpilot/backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 2. Frontend Setup
cd researchpilot/frontend
npm install
npm run dev
```
